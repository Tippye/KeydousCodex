Codex 旋钮

左转切换上一个任务，右转切换下一个任务，按下唤起 Codex。

应用会先聚焦已打开的 Codex 窗口。仅配置普通层，Fn 层保持原样；Codex 中有多个标签时也会切换标签。请保留 Codex 默认的 Ctrl + Page Up / Page Down 快捷键。

启用后请保持本程序运行。关闭程序会停止响应，键盘映射会保留；下次启动自动恢复热键服务。“恢复旋钮”只还原启用前的三个动作。

本程序会占用 Ctrl + F9 / F10 / F11；其他键盘按下相同组合也会触发。
